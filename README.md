## User Login & Authentication Server

This server provides user login and authentication functionality built on the MCP framework.

It extends the base Phrase Registry server with fully implemented authentication logic and demonstrates how server commands are used in practice.

## Video Walkthrough
For a detailed explanation of how to operate the server and use its commands, watch the video below:

**VIDEO LINK:**  
https://www.youtube.com/watch?v=SP9bbAk_pSs

## Running the Server

Run the server from the Python terminal:

```bash
uv run server phrase_registry stdio
```
